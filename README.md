# Universal Design Intelligence v1.0

General-purpose design and frontend intelligence for creating original, high-quality websites and interfaces. Researches the brief and constraints, develops project-specific art direction, composes intentional layouts, implements polished UI, and iterates against real renders. No fixed aesthetic or layout template.

## Core Philosophy

**Brief before aesthetic.** Understand what the site/product is, its audience, primary actions, content, constraints, brand, and success criteria before choosing a visual direction.

**No house style.** Do not default to dark mode, gradients, glass, grids, oversized type, cards, rounded corners, animations, 3D, or minimalism. These are options—not signatures.

**Design from purpose and content.** Content hierarchy, information architecture, and task flows determine composition. Never invent sections merely to fill a familiar page pattern.

## Workflow

1. **Understand and inspect** — Read brief, inspect repo, establish verified facts
2. **Research selectively** — Targeted research for unfamiliar patterns, libraries, references
3. **Develop design direction** — Coherent concept, visual character, palette, typography, composition
4. **Structure before decoration** — IA, layout, responsive behavior before effects
5. **Implement with craft** — Use project stack, semantic HTML, accessibility, real states
6. **Visual and functional critique** — Inspect actual renders, fix issues, re-verify
7. **Final pass and delivery** — Build, lint, test, confirm, summarize

## Quality Bar

- **Purposeful** — every component and effect has a reason
- **Clear** — primary task and content hierarchy immediately understandable
- **Coherent** — typography, color, spacing, shape, imagery, motion feel related
- **Distinct** — avoids generic template appearance
- **Polished** — responsive details, states, spacing, alignment, transitions considered
- **Credible** — no fake content, fabricated statistics, visual gimmicks, placeholder artifacts
- **Efficient** — fast, accessible, maintainable, appropriately simple
